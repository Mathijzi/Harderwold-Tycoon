Harderwold Tycoon - API (prototype fase 1-3)

Basis-URL: /api/v1 · OpenAPI: /api/v1/openapi.json · Realtime: Server-Sent Events op /api/v1/stream (fallback polling: /api/v1/events?after=cursor). Spelers authenticeren met Authorization: Bearer <token>; beheer met X-Admin-Key. Een spelerstoken heeft nooit admin-rechten.

Slagboomregel

Een inrijdende auto sluit aan in de wachtrij en krijgt een check-in-opdracht; een vertrekkende auto krijgt bij de uitrijslagboom een check-out-opdracht. Alleen het geautoriseerd afronden van precies die opdracht maakt één eenmalig passagetoken aan (gekoppeld aan voertuig, richting, opdracht en spel). De servercontroller verbruikt het token pas als dat voertuig vooraan bij de stopstreep staat: CLOSED → OPENING → OPEN → CLOSING → CLOSED, en sluit pas als het voertuig de doorrijzone volledig heeft verlaten. Animaties, nabijheid, timers of "hervatten" openen nooit een slagboom. De noodbediening (/admin/gates/{id}/override) vereist een reden en wordt gelogd.

Projectie: URL-parameters

Zet ze achter het adres van de projectie, gescheiden door &. Voorbeelden: /?res=4k (beamer), /?zoom=3&focus=receptie (close-up op een tweede scherm), /?hour=22&sound=0 (nachtbeeld testen zonder geluid). Andere pagina's: /admin (spelleider), /test (testinterface), /editor (kaarteditor), /docs (deze pagina).

Snelstart met curl

BASE=http://localhost:8090/api/v1
# 1. aanmelden
TOKEN=$(curl -s -X POST $BASE/sessions/join -H 'content-type: application/json' \
  -d '{"gameCode":"HARDER","displayName":"Mathijs"}' | sed -E 's/.*"token":"([^"]+)".*/\1/')

# 2. aankomst laten plaatsvinden (spelleider)
curl -s -X POST $BASE/admin/arrivals -H 'X-Admin-Key: gm-harderwold' -H 'content-type: application/json' -d '{"count":1}'

# 3. wachtende check-in opdrachten
curl -s "$BASE/tasks?state=offered" -H "Authorization: Bearer $TOKEN"

# 4. claimen en afronden (idempotencyKey verplicht; herhalen met dezelfde sleutel is veilig)
TASK=T-checkin-car-010
curl -s -X POST $BASE/tasks/$TASK/claim    -H "Authorization: Bearer $TOKEN" -H 'content-type: application/json' -d '{"idempotencyKey":"c-1"}'
curl -s -X POST $BASE/tasks/$TASK/complete -H "Authorization: Bearer $TOKEN" -H 'content-type: application/json' -d '{"idempotencyKey":"d-1"}'

# Onderhouds- en natuurmeldingen (TD): na het claimen rijdt een golfkar naar de bungalow.
# Afronden geeft 409 technician_not_on_site tot de monteur binnen is; zie het veld technician in GET /tasks/$TASK.

# 5. realtime meekijken
curl -N "$BASE/stream"
