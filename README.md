# Harderwold Tycoon

4K-vakantieparksimulator (fan-/spelprototype, geen officiële band met Harderwold Villa Resort of Landal). Losstaande spin-off van de motor van Aelderholt Tycoon (momentopname 98a274d).

- Starten: `npm install && npm run build && npm start` → `http://localhost:8090/`
- Controles: `npm test`, `npm run multiseed`
- Zie `HANDOFF.md`, `START_HIER.md` en `docs/RUNBOOK.md`.
